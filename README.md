# Jev 判定ツール

Node.js 18以上が必要です。`TYPESAFE_API_KEY` を環境変数に設定したターミナルで起動します。

```bash
npm start
```

ブラウザで http://127.0.0.1:3000 を開いてください。APIキーをシェル設定ファイルに追加した場合は、新しいターミナルを開くか設定を読み直してください。

画面から送る質問型は `choice` です。判定材料、判断内容、回答候補を入力して送信すると、Jevの `probabilities` を候補別の割合で表示します。結果の「Jevに送った内容」を開くと、実際に送った値を確認できます。APIキーはサーバー側だけで読み取り、画面には送りません。停止はターミナルで Ctrl+C です。
